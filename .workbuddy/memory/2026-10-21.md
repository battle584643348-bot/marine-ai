## git 操作中踩到的两个细节
1. **`git branch -d` 的判定对象是「上游分支」不是 HEAD**：
   已合进 main 但 `origin/feature/download-link` 停在旧提交时，`-d` 仍会拒绝，
   提示 "not yet merged to refs/remotes/origin/...，even though it is merged to HEAD"。
   正解：先 `git push origin --delete <分支>` + `git fetch --prune`，再 `git branch -d`。
2. `git push origin --delete` 被 `&&` 串在 `git branch -d` 之后，前者失败导致后者
   根本没执行 —— 排查时注意命令链的短路行为。
