## 第四课：完整版本控制闭环（含第一个真实修复）
- 用真实单行修复演示全流程：`requirements.txt` 补 `rapidocr_onnxruntime>=1.3`
  （源码 `diagram_annotate.py:354` 有 `from rapidocr_onnxruntime import RapidOCR`，
  但依赖从未声明 → 新环境静默降级）。以**可选依赖**形式加入并注释降级行为，
  不下沉为必需依赖（含 onnxruntime，体积大，仅 sld 栅格图路径需要）。
- 走的完整链路：`git switch -c fix/requirements-ocr` → 编辑 → `status -sb`
  → `git diff` → `git add` → `git diff --staged` → commit（`df52b41`）
  → `switch main` → `merge`（Fast-forward）→ `push` → `branch -d`。
- 教学要点：` M` 与 `M ` 两位的含义（左=暂存区、右=工作区）；
  Fast-forward 的含义（main 未动过时只挪指针、不产生 merge commit）；
  `branch -d` 对未合并分支会拒绝（安全阀）。
- 待补：撤销矩阵（restore / restore --staged / reset / revert / stash）只讲了没实操。
