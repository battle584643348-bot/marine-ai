本机：RTX 5060 4GB + 16GB 内存 · Ollama 未装 · 当前 LLM provider = mock（离线占位）
技能离线能力分层
技能层说明
calc_engine 工程计算完全离线 ✓ 确定性公式计算，零网络零模型
diagram_annotate 单线图标注完全离线 ✓ pymupdf/openpyxl 本地处理 PDF/Excel
excel_report Excel 报告完全离线 ✓ 本地生成工作簿
knowledge_search 知识检索完全离线 ✓ 内置 TF-IDF 关键词检索（无需 embedding 模型）
standard_lookup 标准速查完全离线 ✓ 本地标准库速查
translate 中英翻译需本地模型 ⚠ 走 LLM —— 当前 mock 为占位，装 Ollama 后离线可用
sop_generator 调试程序需本地模型 ⚠ 走 LLM —— 同上
对话问答（全部 8 分支）需本地模型 ⚠ Agent 循环 + 技能调度，模型决定对话质量
另有可选云端：openai 兼容（DeepSeek 等，需联网+key）——不装本地模型时也可在线用，但不满足"离线"要求。
离线能力现状（无网络时）
5 个技能完全可用
3 个技能 + 对话 = mock 占位
系统自带 provider: auto —— 启动时自动探测本地 Ollama，检测到即切换离线推理，无需改代码。
三步落地：让全部技能离线可用
1
安装 Ollama（本地推理服务）
winget install Ollama.Ollama 或官网 ollama.com 下载 ~700MB
2
拉取中文对话模型（按本机 16GB 内存 + 4GB 显存）
ollama pull qwen2.5:7b（约 4.7GB，质量/速度平衡，推荐）
或 ollama pull qwen2.5:3b（约 2GB，更快更省）
可选语义检索：ollama pull bge-m3
3
配置并重启：
① 前端「设置」页选 Ollama 并填模型名；或
② 直接改 config.yaml → llm.provider: ollama
③ 重启服务 → 状态显示 Ollama 可达；模型 qwen2.5:7b 已安装
完成后断网重启验证：对话、翻译、SOP、全部技能均在本机推理，零外网请求（前端零 CDN 已确认）。
