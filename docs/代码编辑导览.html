前端

frontend\（浏览器里看到的界面）

改完保存 → 刷新页面即生效，无需重启
文件管什么常见修改
index.html页面结构：侧边栏 / 对话区 / 欢迎页 / 导航加按钮、改标题、调整布局骨架
css/style.css全部样式：颜色、字号、间距、深浅主题改 --accent 主色、字体、卡片样式
js/app.js主逻辑：消息渲染、分支切换、视图导航改欢迎语、分支切换行为、消息样式
js/api.js所有后端请求封装（fetch/SSE）后端接口变了就改这里
js/docs.js / skills.js / settings.js知识库页 / 技能页 / 设置页逻辑调整各页面交互
js/markdown.jsMarkdown → HTML 渲染一般不动
后端

backend\app\（API 与逻辑）

改完保存 → 必须重启服务才生效
文件管什么常见修改
main.pyFastAPI 入口：路由注册、静态托管、状态初始化加新路由、改托管路径

skills/*.py（6 个技能）技能实现：标准速查 / 计算 / SOP / 翻译 / Excel / 检索改技能逻辑、加新技能（复制一个类改）
skills/registry.py · base.py技能注册表与基类（自动发现）一般不动

数据与配置

config.yaml + data\（不用写代码，改配置）

改完重启服务生效（user_config.yaml 页面设置是动态加载）

data/index.json · uploads\RAG 索引与上传文档不要手改，用页面操作
流程

编辑 → 生效的标准流程

1. 找到文件改对应 .py / .js / .json，用 VS Code 等打开
→
2. 保存前端改完直接刷新浏览器（必要时 ?fresh=时间戳 强制重载）
→
3. 后端重启结束占用 8000 端口的 python 进程 → python run.py 重新启动
→
4. 验证浏览器打开 http://127.0.0.1:8000 测试改动
提示：重启后端用命令 python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000，或直接 python run.py（项目根目录下）。
