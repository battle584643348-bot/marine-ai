② 安装与配置步骤

1
安装 VS Code（进行中）

命令：winget install Microsoft.VisualStudioCode；也可官网 code.visualstudio.com 手动下载

2
装中文语言包 + Python 插件

VS Code 扩展市场搜 Chinese (Simplified) 和 Python（含 Pylance 语法检查、代码补全、调试）

3
用 VS Code 打开项目

文件 → 打开文件夹 → 选择 marine-ai 根目录

4
内置终端启动后端

终端（Ctrl+`）→ python run.py，访问 http://127.0.0.1:8000

5
开始编辑

前端改 frontend\ 保存后浏览器刷新即生效；后端改 backend\app\ 保存后重启 python run.py

③ 编辑—运行闭环

改什么在哪改如何生效
界面样式 / 文案 / 交互frontend\（html/css/js）保存 → 浏览器刷新（必要时 ?fresh=时间戳）
接口 / 技能 / Agent 逻辑backend\app\（.py）保存 → 终端停掉旧进程 → 重新 python run.py
分支 / 标准 / 参数data\*.json、config.yaml重启服务生效
调试技巧：VS Code 的 Python 插件支持断点调试——在 main.py 按 F5 即可图形化断点、看变量，适合排查后端逻辑。

④ 可选增强（推荐）

项目作用做法
Python 虚拟环境 venv隔离依赖，避免污染全局 Python项目根执行 python -m venv .venv，之后用 .venv\Scripts\activate 激活再启动
Git 初始化记录每次修改，可回滚项目根 git init → 定期 git commit
Ollama 本地模型替换 mock 模式，真正用大模型回答ollama.com 下载 → ollama pull qwen2.5:14b → 设置页选 Ollama
