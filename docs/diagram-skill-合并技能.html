diagram_annotate · 单线图系统标注
一个技能 · 两种模式 · 三个输出 —— 由 mark_lighting_diagram.py 与 mark_sld_diagram.py 合并封装
已注册 · 已启用 drawing 分支已挂载

单线图 PDF
照明图 / 开关柜 SLD 原图
→
电缆清册 XLSX
CABLE TAG · TO EQUIP · SYSTEM NO · SYSTEM DESCRIPTION
模式分发（参数 mode）
lighting · 照明/配电
① CKT/LOOP 回路识别
② 配电板框 + 回路框
③ 标签：<系统号>-<回路号> / LOOP-<回路号>
④ 中文 FreeText（china-s，福昕可编辑）
sld · 开关柜
① 表头列自动定位（兼容不同排版）
② P 动力电缆馈线锚点 + 设备框
③ 母线 BUSBAR 框 + 盘号识别
④ 栅格化图纸自动 RapidOCR（可选）
⑤ 识别结果回填清册副本
输出三件套（generated/diagram_mark/）
① 系统标注 PDF
注释框+可编辑标签，不烘焙图纸
② 未匹配电缆清单.xlsx
图纸未匹配 + 清册未上图
③ 清册_含SLD识别.xlsx
仅 sld 模式 · 新增 SLD识别结果 工作表 · TBA 灰底

使用方式（在「图纸智能」分支对话即可）
照明图 → 上传 PDF，说“按系统标注这张照明单线图”
开关柜 → 上传 PDF，说“给这张 690V 开关柜单线图做 SLD 系统标注，并回填清册”
技能参数：mode=lighting/sld · input_pdf=图纸路径 · schedule=清册路径（默认桌面补全版）· sheet=cable schedule
